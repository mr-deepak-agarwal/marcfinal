# MARC Glocal Website - PRD

## Original Problem Statement
Update MARC Glocal website (Next.js 14) to align with brand guidelines:
- Replace stock market graphics with geometric shapes
- Use brand color palette (Green 3 #4E9141, Turquoise #5D9F94, Light Green #C2DDB4)
- Add Indian saffron/amber section dividers (#92400E)
- Add Careers section with company values
- Update Contact page with all office locations
- Use Poppins font throughout
- SEO improvements

## Tech Stack
- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + Shadcn UI
- **Font:** Poppins (Google Fonts)
- **Deployment:** Vercel

## Brand Color Palette
| Color | Hex Code | Usage |
|-------|----------|-------|
| Green 3 | #4E9141 | Primary (Hero, buttons, accents) |
